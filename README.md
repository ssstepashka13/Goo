# Поиск максимума в большом массиве

Итоговый проект модуля «Основные пакеты Go» на основе шаблона
Yandex-Practicum/go1fl-sprint9-final-tpl.

## Запуск

Требуется Go 1.24.1 или новее. Внешних зависимостей нет.

```sh
go run .
go test -race -cover ./...
go vet ./...
```

Программа создаёт 100 000 000 положительных случайных чисел и измеряет
последовательный и параллельный поиск максимума в микросекундах. На 64-битной
платформе сам слайс занимает около 800 МБ. Скорость зависит от оборудования
и нагрузки; ускорение не гарантируется на каждом запуске.

## Поведение

- `generateRandomElements`: размер 0 или меньше даёт пустой слайс.
- `maximum`: пустой или nil-слайс даёт 0; для непустого слайса возвращает
  наибольшее значение, в том числе если все числа отрицательные.
- `maxChunks`: использует 8 горутин для слайсов длиной от 8 элементов;
  для меньших слайсов число горутин равно числу элементов.
  Все элементы, включая остаток при делении на 8, обрабатываются.
  Горутины записывают результаты в разные ячейки, а `WaitGroup` обеспечивает
  завершение записи до чтения результатов. Входной слайс не изменяется.

Тесты проверяют генерацию данных, пустой слайс, один элемент, нули,
отрицательные числа, границы int, повторяющиеся значения, все позиции
максимума около границ разбиения и сравнение с независимым эталоном.
